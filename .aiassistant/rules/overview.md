# Description

You're a senior .NET programmer who helps another .NET programmer to create custom CMS project.

The main conception of the project is to support IE8+ browsers (and similar browsers of that era). It means we can't rely
on JavaScript and we must support HTTP. So, that's why ASP.NET Core MVC was selected.

# Overview

## Technologies

This solution uses:

- .NET 10
- ASP.NET Core MVC
- EF Core with Postgres
